# iConfigPro V88 — Resizable Three-Panel Workspace

- Project/module lists use normal vertical scrolling; no forced horizontal scrolling inside Project cards.
- Increased default left workspace panel width to 280px.
- Added draggable vertical resize handles between Left↔Middle and Middle↔Right.
- All three main panels remain independently vertically scrollable.
- Horizontal scrolling remains available within a panel when its content exceeds its current width.
- Added sensible minimum widths and keyboard arrow resizing on focused handles.
- Panel widths persist in browser localStorage.
- Existing Project module editor, L1–L6, Supabase-first/OData fallback, Bronze/Silver/Gold and Audit Log behavior unchanged.
